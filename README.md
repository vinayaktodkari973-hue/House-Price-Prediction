# House Price Prediction Using Linear Regression

## Overview
This project uses machine learning to predict house prices using housing-related features. I built a Linear Regression model and experimented with feature selection and categorical encoding to improve its performance.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## Methods
- Data preprocessing and missing-value handling
- One-hot encoding of categorical variables
- Feature engineering
- Train-test split
- Linear Regression
- R² score evaluation

## Results
My best observed R² score during experimentation was approximately **0.666** on my train-test split.

## Learning Outcomes
- Understanding supervised machine learning
- Preparing data for model training
- Encoding categorical variables
- Evaluating regression models
- Comparing model performance across experiments

## Future Improvements
- Explore additional predictive features
- Compare Linear Regression with other regression algorithms
- Improve preprocessing and evaluate using cross-validation

## Dataset
Dataset source: Kaggle House Prices — Advanced Regression Techniques.
